# Changelog

## 0.1.2 - 2026-07-10

- Supports Pi's `max` thinking/reasoning level in `/session-model <provider>/<model>:max`.

## 0.1.0

- Initial release.
- Adds `/session-model` slash command for per-session model and thinking-level switching without changing global defaults.
- Supports argument completion for providers and model references.
- Supports optional `provider/model:thinking-level` syntax (e.g., `anthropic/claude-sonnet-4-5:high`).
